## Projeto em destaque

### Ever Rise

A **Ever Rise** é um projeto de guincho hospitalar autônomo criado para auxiliar na transferência de pessoas com mobilidade reduzida.

O objetivo é trazer mais segurança, autonomia e acessibilidade para famílias, cuidadores e profissionais da saúde.

Tecnologias e conceitos envolvidos:

- Interface web para controle do guincho
- Sensores de segurança
- Monitoramento de sessão
- Banco de dados
- Prototipagem
- Experiência do usuário
- Tecnologia assistiva
